# Food Ordering System

Full-stack food-ordering project with a responsive storefront, admin interface, Express API and MongoDB persistence.

## Features

- Product browsing, shopping cart and checkout
- Order management interface
- Express REST API and MongoDB storage

## Run locally

1. Open `Backend`, run `npm install`, and copy `.env.example` to `.env`.
2. Add your own MongoDB Atlas URI and run `npm start`.
3. Open `Webbanhang-main/index.html` with a local web server.

The MongoDB connection string is never committed.
